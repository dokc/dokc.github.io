Apache Kafka is more than just a messaging broker. It has a rich ecosystem of different components. There are connectors for importing and exporting data, different stream processing libraries, schema registries, and a lot more. In this talk, Senior Principal Software Engineer at Red Hat [Jakub Schultz](https://www.linkedin.com/in/scholzj/), shows how to use Kafka to read data from social networks such as Twitter, process them and use machine learning to analyze them. With everything running on top of Kubernetes.
