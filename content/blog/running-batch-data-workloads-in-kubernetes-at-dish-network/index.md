This DoK Town Hall explored optimizing batch data processing at scale on Kubernetes, addressing the challenges of fast, reliable data processing in the face of exponential data growth. It showcased an architecture leveraging Apache Spark Operator, Apache YuniKorn, Karpenter, and Argo Workflows. This approach aimed to enhance resource allocation, storage performance, and job scheduling, demonstrating how businesses can efficiently handle large-scale data processing for improved decision-making.

Speaker:

- [David Fox](https://www.linkedin.com/in/david-m-fox/) - PHD, Dish Networks
