An honest discussion about the challenges of running stateful, distributed applications inside of Kubernetes. This talk features [Umair Mufti](https://www.linkedin.com/in/umairmufti/), former Manager of Data Services at DreamWorks where he led the development of a Kubernetes-based, Database-as-a-Service platform. Currently building products for [Portworx](https://portworx.com/) that incorporate all the lessons learned from managing enterprise-grade databases on Kubernetes.

The talk discusses what extensions need to be made for Kubernetes to allow proper handling of cluster topologies, leader election, membership/failure detection, sharded ingress, service discovery, operator, and more.
